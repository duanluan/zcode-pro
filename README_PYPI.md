# ZCode Pro

ZCode 桌面版界面增强工具，不修改客户端文件。核心功能：项目自定义别名。

## 安装

```sh
pip install zcode-pro
```

前提：本机已安装 ZCode 桌面版（优先复用其自带的运行时，无需另装 Node.js）；未安装 ZCode 时需要 Node.js >= 22。

也可以通过 npm 安装：`npm install -g zcode-pro`

## 使用

```sh
zcode-pro          # 启动带增强的 ZCode
zcode-pro --help   # 查看全部选项
```
