# 插件卡片遮罩由 zcode-pro 注入，插件页面不感知

壁纸开启时 zcode-pro 会往插件沙箱页（`zcode-sandbox://` 的 webview/iframe）注入透明背景，让壁纸从卡片透出；卡片内的磨砂与底色由各插件自己的 CSS 决定，zcode-pro 管不到，用户嫌卡片太亮/太透时没有办法整体调。决策：壁纸设置里增加“插件卡片遮罩”滑杆（0–100%），由 zcode-pro 往所有插件沙箱页注入一层主题色遮罩（颜色取当前 `--color-background` 的计算值，透明度取滑杆值）。不依赖插件配合；默认 20%；壁纸关闭时该行不显示。

## Considered Options

- 与 vision 插件约定 CSS 变量（`--zcodepro-card-veil`）精确改它的白雾面：只对配合的插件生效，其它插件卡片（rtk、headroom、open-code-review）无法统一压暗，与“壁纸开着所有插件卡片都要适配”的要求冲突，放弃。
- 直接覆盖插件页内部类名（`.qa` 等）：依赖单个插件的内部实现，跨插件不可用，升级插件就失效，放弃。
- 每个插件自己加设置：入口分散到各插件，用户找不到，也做不到“壁纸 tab 里统一调”，放弃。

## Consequences

- 遮罩是垫在卡片底下的通用层：能统一调暗所有插件卡片的透出效果；但卡片表层自带的底色只能被间接压暗，要精确控制仍是插件自己改（本次 vision 卡片的深色样式改为深灰实底，避免宿主切浅色后旧卡片收不到换肤通知、白字看不清）。
- 注入顺序：宿主侧静态透明脚本（文档创建时注入）先、页面侧 `insertCSS` 后，同特异性 `!important` 后者生效；配置变化时先撤旧 key 再重插。
- 遮罩颜色取 `--color-background` 的计算值再归一化成 rgb（与壁纸遮罩同一套取色，明暗与皮肤自动跟随），官方主题与自定义皮肤都适用。
- 壁纸关闭时卡片本来就不透，滑杆整行隐藏，避免无效设置。
